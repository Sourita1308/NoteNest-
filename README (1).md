# RAG Study Chatbot 📚

> An AI-powered study assistant that answers questions from your own lecture notes and PDFs — built with RAG (Retrieval-Augmented Generation).

## Features (14-day roadmap)
- [x] Day 1–3: Core RAG — upload PDFs, ask questions, get cited answers
- [ ] Day 4–6: Voice I/O + multilingual support
- [ ] Day 7–8: Socratic tutor mode
- [ ] Day 9–10: Auto quiz generator
- [ ] Day 11–12: Spaced repetition memory system (SM-2)
- [ ] Day 13: Mind map visualizer

## Setup

### 1. Clone and install
```bash
git clone https://github.com/YOUR_USERNAME/rag-study-chatbot
cd rag-study-chatbot

python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Configure API keys
```bash
cp .env.example .env
# Edit .env and add your OpenAI or Gemini API key
```

### 3. Add your PDFs
```bash
mkdir data
# Copy your lecture PDFs into the data/ folder
```

### 4. Ingest documents
```bash
python ingest.py
# For custom folders:
python ingest.py --data_dir ./my_notes --persist_dir ./vectorstore
```

### 5. Run the chatbot
```bash
streamlit run app.py
```

## Tech stack
| Component | Technology |
|-----------|-----------|
| LLM orchestration | LangChain |
| Vector database | ChromaDB → Pinecone |
| Embeddings | HuggingFace all-MiniLM-L6-v2 |
| LLM | GPT-3.5-turbo / Gemini |
| Voice | Whisper + ElevenLabs |
| UI | Streamlit |
| Memory algorithm | SM-2 (Anki) |
| Database | SQLite |

## Architecture
```
[PDFs] → [Text splitter] → [Embeddings] → [ChromaDB]
                                               ↓
[User question] → [Embed query] → [Similarity search] → [LLM] → [Answer + sources]
```
